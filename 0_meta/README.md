# 0_meta

Der Rahmen des Repositories selbst — nicht der Inhalt, sondern die Regeln darüber.

| Datei | Inhalt |
|---|---|
| `projektkontext.md` | Ziel, Umfang der Beauftragung, Abgrenzung |
| `glossar.md` | was ein Wort bedeutet |
| `konventionen.md` | Ordner, Dateinamen, Format, Frontmatter, Verweise |
| `entscheidungen.md` | was entschieden ist: F für Format und Repository, E für Inhalte |
| `offene-punkte.md` | was noch zu entscheiden ist |
| `quellen/` | die Dokumente, auf die sich das Repository beruft |

Entscheidungen und offene Punkte sind getrennt, weil sie verschieden lange
leben: Offene Punkte verschwinden, wenn sie geklärt sind. Entscheidungen bleiben
dauerhaft nachlesbar, auch die, die später revidiert werden.

Das Entscheidungslog wird gebündelt am Ende eines Arbeitstages geschrieben, nicht
laufend während der Arbeit.
