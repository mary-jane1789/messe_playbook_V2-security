# Glossar

Begriffe, die im Repository verbindlich verwendet werden — je Begriff eine
Definition und, wo nötig, die Abgrenzung zu einem ähnlichen Begriff.

Noch nicht befüllt.

Vorgesehen:

- **Gate** — Bedingung an einem Phasenübergang. Definition bei der Migration aus
  Playbook V1.0, Kap. 2. Abzugrenzen gegen den Check-Point: Ein Gate ist eine
  Bedingung an einem Phasenübergang, ein Check-Point eine Übergabe zwischen zwei
  Rollen, meist innerhalb einer Phase.
