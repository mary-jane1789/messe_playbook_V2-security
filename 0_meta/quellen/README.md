Eine Ausnahme von der Regel „hier wird nichts verändert" ist
`veranstaltungssicherheitskonzept-anonymisiert.md`. Das Dokument ist die
anonymisierte Fassung eines fremden veranstaltungsbezogenen Sicherheitskonzepts:
Veranstaltung, Veranstalter, Ort, Dienstleister, Behörden, Aussteller und alle
Personendaten sind entfernt, branchenspezifische Formulierungen verallgemeinert,
Kalenderdaten in relative Phasenangaben überführt. Es dient als Referenz für
Struktur und Themenumfang eines Sicherheitskonzepts und ist kein Beleg für
Aussagen über die eigene Messe. Das Original liegt nicht im Repository.
