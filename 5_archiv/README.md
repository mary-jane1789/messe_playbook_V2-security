# 5_archiv

Artefakte: was aus dem Repository herausgegangen ist — Decks, Exporte,
Dokumentfassungen, herausgegebene Steckbrief-Vorlagen — und abgelöste Stände.

Dazu die ausgefüllten Rückläufe aus dem Fach, nachdem sie ausgelesen sind.
Sie sind der Beleg dafür, was das Fach tatsächlich gesagt hat; das `quelle`-Feld
des Moduls verweist darauf.

Unterschied zu `0_meta/quellen/`: Dort liegt, worauf sich das Repository beruft
und was gilt. Hier liegt, was es verlassen hat oder nicht mehr gilt.
