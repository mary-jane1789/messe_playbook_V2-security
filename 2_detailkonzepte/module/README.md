# module

Die Bereichs-Detailkonzepte — Ausdetaillierung des Schemas
`1_grundkonzepte/modul.md` für je einen Bereich.

Je Bereich ein Ordner, benannt `<bereich>-module-detailkonzept/`. Angelegt wird
er, wenn der Bereich beauftragt ist.

Die ausgefüllten Module desselben Bereichs liegen in
`3_instanzen/module/<bereich>-module-instanzen/`.
